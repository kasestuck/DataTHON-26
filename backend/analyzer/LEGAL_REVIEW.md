# Категории для правовой проверки

Подтверждённых нормативных оснований нет для всех 18 категорий. Ссылки на акты
Республики Казахстан не добавлены. Это список вопросов для проверки, не вывод о
нарушении и не инструкция автоматически считать событие противоправным.

| Группа | ID | Что потребуется установить отдельно |
|---|---|---|
| Наличные | `cash_split_transfer`, `cash_left_unattended`, `cash_not_secured_between_clients` | Применимое правило обращения с наличными, контекст операции и исключения |
| Предметы и документы | `items_left_unattended`, `documents_left_unattended`, `personal_items_on_counter`, `drinks_at_workstation` | Применимость требований к конкретной зоне, предметам и данным |
| Двери и ключи | `key_left_in_safe`, `safe_door_open`, `cash_room_door_left_open` | Какой объект виден, режим доступа, применимое требование и исключения |
| Люди и доступ | `third_person_at_counter`, `uncontrolled_access`, `customer_leaves_during_count` | Полномочия участников и контекст; присутствие само по себе их не устанавливает |
| Проверки | `identity_check_not_visible`, `cash_bag_received_without_visible_check` | Полнота видеоконтекста, доступные способы проверки и применимое требование |
| Требуют уточнения | `cash_bag_handling`, `banknotes_disordered`, `workstation_left_active` | Объект действия, признаки состояния и само содержание предполагаемого правила |

Последние шесть ID (две категории проверок, три категории уточнения и
`uncontrolled_access`) отключены для автоматической выдачи. Для остальных
разрешено обнаружение визуального события с кадрами, а юридическое основание
остаётся `unverified` в отдельной политике. Для `cash_room_door_left_open`
открытая дверь не доказывает обязанности её закрыть. Для неупорядоченной стопки
не утверждаются разные номиналы. Для действий с сумкой объект разрезания не установлен.
