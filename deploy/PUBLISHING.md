# HTTPS-демонстрация Forte Vision

Публичный доступ пока **не открыт**. Подготовка не создаёт туннель, URL или учётную запись. Открытие выполняется только отдельной командой после подтверждения владельца проекта.

## Сейчас: проверка готовности без публикации

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\start-public.ps1
```

Проверяются Python, локальные веса и SHA256 cloudflared. По умолчанию скрипт завершает работу, не запуская ни сайт, ни туннель.

На этой машине cloudflared 2026.10.1 уже скачан в исключённый из Git `.tools/` из [официального релиза](https://github.com/cloudflare/cloudflared/releases/tag/2026.10.1). SHA256 Windows amd64: `4d2490e74082c5d48dbfedaf92576fa5bd1702379ab88eb7faa0cfbe8dc891b6`. На другой машине скачайте `cloudflared-windows-amd64.exe` из этого релиза, сохраните как `.tools/cloudflared.exe` и проверьте хеш. Иная версия требует отдельной проверки; launcher не запустит неподтверждённый бинарный файл.

## Только после отдельного подтверждения публикации

Сначала остановите свою локальную копию сайта через Ctrl+C. Launcher откажется запускать вторую копию на занятом порту и не завершает чужие процессы.

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\start-public.ps1 -Publish
```

Скрипт получает временный HTTPS URL Quick Tunnel, пока порт приложения ещё закрыт, затем запускает существующий `start.ps1` с точным `-PublicOrigin`. API продолжает слушать только `127.0.0.1:8001`. Проброс портов роутера, Windows-служба, Docker и Node-сервер не создаются. Файлы сайта раздаются тем же FastAPI из `frontend/`. Для другого свободного порта можно добавить `-Port 8080`.

Cookie браузерной сессии с первого запроса имеет Secure, HttpOnly и SameSite=Strict. Ключ API генерируется только в окружении Python-сервера и в JavaScript не передаётся. Uvicorn доверяет forwarded-заголовкам только от `127.0.0.1`, откуда приходит cloudflared. При заданном PublicOrigin для браузера используйте HTTPS URL, а не локальный HTTP адрес; `/health` на loopback остаётся доступным.

Держите окно запуска открытым. Ctrl+C останавливает только запущенные этим скриптом сайт и туннель. При аварии одного процесса второй также завершается. Логи находятся в игнорируемом `var/public-demo/`; уровень debug не включается, чтобы не записывать заголовки запросов. В Git не добавляются логи, ключи, бинарный файл, веса или видео.

Quick Tunnel не требует домена или аккаунта, но адрес меняется при перезапуске и нет гарантии доступности. Любой обладатель URL может открыть сайт: существующий браузерный интерфейс не требует входа. Это временная демонстрация, не постоянно размещённый сервис. [Официальное описание Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

## Обязательная проверка после разрешённого открытия

1. Открыть выданный HTTPS URL из внешней сети, например на телефоне через мобильный интернет.
2. Проверить `/health`, HTML/CSS/JS, cookie Secure/HttpOnly и отсутствие X-API-Key в браузерных запросах. `/api/v1/*` без ключа должен отвечать 401; браузер использует `/ui-api/v1/session`, `/ui-api/v1/analyze`, `/ui-api/v1/jobs/{job_id}`.
3. Загрузить **синтетический MOV без банковских данных**, получить job_id, дождаться `done` либо корректного `failed`, проверить JSON и отображение результата. AI остаётся настоящим и локальным.
4. Проверить загрузку около 29 МБ. Локальный лимит — 100 МиБ; у провайдера может действовать собственный меньший предел. До реальной проверки через HTTPS не считать внешний upload подтверждённым.
5. При наличии разрешения на передачу конкретного банковского ролика проверить и его: при находке должны отображаться таймкод и 1–3 JPEG на событие. **Туннель Cloudflare передаёт трафик через внешнего провайдера**, хотя нейросети работают локально. Подтверждение публикации не заменяет разрешения на передачу приватных записей. Датасет жюри не используется для обучения.
6. Проверить интерфейс на телефоне и ширинах 360/390/768/1440. Предыдущие DOM-проверки не заменяют визуальную проверку. Скриншоты и записи экрана автоматически не создаются.

Асинхронная очередь сохраняется: загрузка возвращает job_id, затем идут короткие polling-запросы раз в 2,5 секунды. Не держите один запрос открытым на все 270 секунд. Очередь — одно видео за раз; внутренний лимит 260 секунд, внешний 270. Ожидание в очереди может увеличить общее время. Laptop должен быть подключён к питанию и интернету, без сна и конкурирующих GPU-задач.

## Если нужен постоянный адрес

Для собственного домена подготовлен `deploy/cloudflared.example.yml` с сервисом `http://127.0.0.1:8001`. Реальные UUID, credentials JSON и рабочую конфигурацию храните вне Git, например в `var/tunnel/`. Создание туннеля и DNS не выполнялось. Нужны доступ к аккаунту и домену; [официальная инструкция](https://developers.cloudflare.com/tunnel/get-started/). Не пытайтесь автоматически менять существующий `.cloudflared/config.yml`: Quick launcher в таком случае остановится для проверки.

Docker-сборка на этой машине пока не проверена и для нативной демонстрации не требуется.
