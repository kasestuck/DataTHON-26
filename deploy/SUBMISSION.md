# Финальный запуск и передача Forte Vision жюри

Production использует только `backend.analyzer:analyze_video`, локальные RT-DETR
и Qwen3-VL-2B. Исследовательские изменения не включены в рабочий pipeline.
Публичный доступ сейчас выключен; подготовка не открывает туннель.

## Запуск на подготовленной Windows-машине

Перед демонстрацией подключите ноутбук к штатному зарядному устройству и убедитесь,
что Windows показывает питание от сети. На проверенной машине работа от батареи
сопровождалась ограничением GPU до 30 Вт и таймаутом VLM; после подключения питания
X-1 обработан через API за 47,32 с с неизменёнными параметрами. Это контрольный
замер одного видео, а не гарантия времени для любого файла. Не запускайте игры
или второй анализатор одновременно с демонстрацией.

Из корня проекта в PowerShell, при готовых `.venv` и локальных весах:

```powershell
# Один и тот же приватный ключ нужен при перезапусках и для жюри.
$env:API_KEY = (Get-Content -LiteralPath .\var\jury-api-key.txt -Raw).Trim()
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Сайт: http://127.0.0.1:8001 . Остановка — Ctrl+C. Запускайте один экземпляр;
не выполняйте прямой inference параллельно с очередью. Ноутбук должен оставаться
подключённым к питанию, без сна и конкурирующих GPU-приложений.

На текущей машине приватный файл ключа подготовлен отдельно от Git. На другой
машине создайте его один раз, если его ещё нет:

```powershell
.\.venv\Scripts\python.exe -c "from pathlib import Path; import secrets; p=Path('var/jury-api-key.txt'); p.parent.mkdir(parents=True, exist_ok=True); p.exists() or p.write_text(secrets.token_urlsafe(32), encoding='utf-8')"
```

Ключ не размещается в README, браузере, репозитории или скриншотах. Сам
`start.ps1` не читает `.env`: переменная должна быть установлена в текущем
PowerShell перед запуском. Без неё launcher генерирует временный ключ только
в окружении дочернего процесса; для передачи жюри используйте шаг выше.

Зависимости и подготовка весов описаны в [README](../README.md). Для обработки
видео после подготовки доступ к облачным AI или интернету не нужен. Веса не
хранятся в Git. Docker для проверенного нативного запуска не требуется.

## HTTPS и API жюри

Сначала остановите локальный сервер. Только после отдельного разрешения
владельца на открытие публичного доступа, в том же PowerShell с `API_KEY`:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\start-public.ps1 -Publish
```

Перед запуском можно проверить подготовку без публикации:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\start-public.ps1
```

Скрипт публикации выводит временный HTTPS URL; он меняется при перезапуске.
Держите окно открытым до окончания проверки. Туннель передаёт трафик через
Cloudflare; модели остаются локальными. Приватные банковские видео через
публичный туннель не передавать без разрешения. Проверку внешней загрузки
начинайте с синтетического MOV. Локальная проверка не заменяет проверку URL
из внешней сети после разрешённого открытия.

API жюри требует заголовок `X-API-Key` на обоих маршрутах. Без ключа или с
неверным ключом возвращается 401. Браузерная сессия не заменяет этот ключ.

```powershell
# Замените адрес на выданный launcher HTTPS URL; для локальной проверки:
$base = 'http://127.0.0.1:8001'
curl.exe "$base/health"
curl.exe -X POST "$base/api/v1/analyze" -H "X-API-Key: $env:API_KEY" -F 'file=@video.mov'
curl.exe "$base/api/v1/jobs/ПОЛУЧЕННЫЙ_JOB_ID" -H "X-API-Key: $env:API_KEY"
```

Формат загрузки — MOV, поле `file`, лимит сервиса 100 МиБ. После получения
`job_id` опрашивайте статус, например каждые 2–3 секунды:

- `processing`: задача в очереди или обрабатывается;
- `done`: `verdict` равен `violation` или `no_violation`, возвращён `violations`;
- `failed`: безопасное сообщение `error`, без отрицательного вердикта.

На каждую находку возвращаются тип, время события, описание и 1–3 JPEG в base64.
Таймаут и ошибка памяти означают `failed`, а не отсутствие признаков нарушения.
Внутренний лимит — 260 секунд, внешний лимит анализатора — 270 секунд.
Официальный предел ответа — 5 минут. Ожидание в последовательной очереди
увеличивает время от загрузки до результата: по возможности передавайте видео
по одному, дожидаясь `done` или `failed`. Одновременная очередь нескольких
загрузок не имеет гарантии завершения каждой в пределах пяти минут от загрузки.

`/health` общедоступен. Сайт доступен обладателям URL без входа; браузерные
`/ui-api/v1/*` используют cookie и CSRF, ключ API в браузер не передаётся.
Сервер раздаёт только `frontend/`, приватные каталоги не публикуются.

## Ограничения и известные ошибки

Результат предварительный и требует проверки специалистом. Production-каталог
содержит 18 визуальных категорий, автоматическая выдача разрешена для 12.
Совпадение с категорией не доказывает нарушение конкретной нормы.

На ранее размеченных 42 видео: TP=11, TN=11, FP=9, FN=11; precision 55%,
recall 50%, F1 52,38%, MAE ближайшего найденного события 6,813 секунды.
MAE не учитывает события без предсказания; её нельзя рассматривать отдельно
от пропусков. Эти показатели не гарантируют качество на новых видео.

Возможны ложные срабатывания на штатной передаче и пересчёте наличных,
открывании сейфа, дверях и присутствии третьего лица; пропуски небольших объектов
и коротких действий; неточные таймкоды. Изменение освещения или ракурса может
изменить ответ. Устойчивость к новой камере не подтверждена. Последний
исследовательский вариант ухудшил контрольный результат и в production не включён.

Нет идентификации лиц, анализа звука, проверки намерений, полномочий,
системных проводок или невидимых действий. Веса не дообучались на видео жюри.
Подтверждённых нарушенных норм в `rules.json` нет: семь категорий имеют только
тематические справки, одиннадцать — незавершённую проверку открытого основания.
Отсутствие ссылки не означает, что открытой нормы не существует.

Docker-сборка на текущей машине не проверена. Временный туннель не гарантирует
постоянного адреса или непрерывной доступности.

## Что передать жюри

1. Действующий HTTPS URL интерфейса и базовый URL API на том же адресе.
2. Маршруты `POST /api/v1/analyze`, `GET /api/v1/jobs/{job_id}`.
3. Значение ключа из `var/jury-api-key.txt` — отдельным приватным каналом.
4. Ссылку на зафиксированный коммит репозитория после разрешённых commit/push.
5. Инструкцию запуска, архитектуру и модели, перечень категорий, источники и
   ограничения из README и `backend/data/RISK_REFERENCES.md`.

Перед передачей убедитесь, что URL отвечает из внешней сети и синтетический MOV
обработан настоящим AI. Датасет, веса, кадры, приватная разметка, отчёты и ключ
в состав публичной передачи не входят. Во время проверки не меняйте конфигурацию.
